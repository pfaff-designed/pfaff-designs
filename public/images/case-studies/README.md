# Case Study Hero Images

This directory contains hero images for each case study project.

## Placeholder Images

The following placeholder images should be added to complete the media setup:

- `capital-one-travel/hero.jpg` - Capital One Travel booking interface
- `pmi-agile-certification/hero.jpg` - PMI Agile certification interface
- `tanger-outlets/hero.jpg` - Tanger Outlets digital experience
- `coca-cola-creative-technology/hero.jpg` - Coca-Cola AI vending machine concept
- `real-estate-platform/hero.jpg` - Confidential real estate dashboard (abstracted)
- `rag-portfolio/hero.jpg` - Generative-UI portfolio interface

## Image Specifications

- **Format**: JPG or PNG
- **Aspect Ratio**: 16:9 (recommended)
- **Minimum Width**: 1200px
- **Recommended Size**: 1920x1080px
- **File Size**: < 500KB (optimized)

## Adding Images

1. Create or obtain hero images for each project
2. Optimize images for web (compress, resize if needed)
3. Place each image in the corresponding project folder
4. Ensure filenames match the pattern: `hero.jpg`

The media registry (`src/lib/media/registry.ts`) already has the paths configured, so adding the actual image files will make them available throughout the application.
